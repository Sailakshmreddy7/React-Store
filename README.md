## Run Locally

Clone the project

```bash
  git clone https://github.com/Sailakshmreddy7/React-Store
```

Go to the project directory

```bash
  cd React-Store
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm start
```
